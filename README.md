# SSC CGL Tier-I Self-Learning Tool

A self-paced learning tool for **SSC CGL Tier-I** preparation.

## Topics covered (so far)
- **Quantitative Aptitude:** Average, Percentage
- **Reasoning:** Analogy, Coding-Decoding, Mirror Images, Series/Pattern
- General Awareness & English: structure ready, content coming soon

## Run locally
```bash
python -m http.server 8765
```
Then open http://localhost:8765/

## Deploy
Auto-deployed to GitHub Pages on every push to `main`.
